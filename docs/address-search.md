# 우리 집 주소 검색

- 주소 검색 공급자: 키 발급이 필요 없는 카카오 우편번호 서비스. 공식 안내: https://postcode.map.kakao.com/guide
- 임베드 검색 창과 공급자 로고를 유지한다. 별도 REST 키나 관광 장소 목록을 주거 주소 DB처럼 사용하지 않는다.
- 선택 결과의 우편번호(zonecode), 선택한 도로명/지번 주소, 법정동 코드(bcode)를 검증한 뒤 앱으로 전달한다.
- 우편번호 서비스는 좌표를 반환하지 않는다. 선택한 기본 주소만 기기 Geocoder로 WGS84 좌표 변환하고, 좌표가 유효할 때 기존 가족 주소 PUT API로 저장한다. API 33 이상에서는 비동기 GeocodeListener를 사용한다.
- Geocoder 미지원·빈 결과·오류·10초 지연은 실패로 안내하며 임의 좌표를 저장하지 않는다. 검색 화면에서 뒤로가면 위치 확인을 취소하고 늦게 온 결과를 반영하지 않는다.
- 웹 검색 스크립트 실패·HTTP 오류·초기화 15초 지연에는 재시도를 제공한다. 좌표 확인 실패 후 다른 결과를 고를 수 있도록 검색 창을 자동 종료하지 않는다.
- KIRI 서버의 현재 가족 정보 응답에는 저장 주소가 없고 주소 조회 GET API도 없다. 따라서 새 화면/다른 기기에서 기존 공용 주소를 조회하는 기능은 서버 계약 확장이 필요하다. 현재 화면의 저장 성공 표시와 서버에서 다시 조회한 표시를 혼동하지 않는다.

검증: PostcodeResultTest, AddressResolutionTest, HomeAddressViewModelTest, PostcodePickerTest, 기존 FamilyAddressApiTest. 공급자 네트워크가 없는 자동 테스트에서는 통제된 웹 완료/오류 콜백을 사용하므로 실서비스 네트워크 확인은 별도 QA로 기록한다.
